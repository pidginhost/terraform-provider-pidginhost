# PidginHost Provider

Manage [PidginHost](https://www.pidginhost.com) cloud servers, volumes, firewalls, public and floating
addresses, private networks, object storage buckets, snapshots and Kubernetes clusters.

Create an API token in the PidginHost panel and pass it as `token`, or export it as `PIDGINHOST_TOKEN`.

## Example Usage

```terraform
terraform {
  required_providers {
    pidginhost = {
      source  = "pidginhost/pidginhost"
      version = "~> 0.2"
    }
  }
}

# Reads the token from PIDGINHOST_TOKEN when token is not set here.
provider "pidginhost" {}
```

Upgrading from 0.1? Read the [0.2 upgrade guide](guides/upgrading-to-0.2).

To deploy to a cluster with the kubernetes or helm providers, read the
[Kubernetes providers guide](guides/kubernetes-providers).
